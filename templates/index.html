About PlacementIQ

A complete student placement analytics and machine-learning decision-support prototype.

🎓 Project Goal

PlacementIQ uses academic performance, assessment scores, background information and engagement indicators to analyze placement outcomes and salary packages.

🧠 What the system demonstrates

Prediction

Estimate placement probability from candidate attributes.

Regression

Estimate salary package in LPA.

Explainability

Surface influential features behind model results.

Segmentation

Group students for targeted career preparation.

⚠️ This is an academic analytics prototype. Predictions should support, not replace, human placement decisions.
